# 大厂招聘帖解读助手

把大厂 AI 产品实习的招聘帖丢给它，它按「底子、产品、AI」三层拆开，每一条都标出原文是哪一句；帖子里没写的（比如工资）直接说「帖子没写」，不自己补。给它简历，它逐条对照说够不够格，不替你编经历。

## 里面有什么
- `规矩.md`：助手的规矩（4 条），装的时候放进「指令 / 项目指令」
- `资料/`：4 条大厂官网 AI 产品实习招聘帖原文（百度、小红书、美团、快手），装的时候作为项目文件上传
- `示例截图/`：实际跑出来的效果

## 怎么装（人看）
1. 在豆包或 ChatGPT 里新建一个「项目」
2. 把 `规矩.md` 的全文粘进项目指令
3. 把 `资料/` 里的文件全部传进项目文件
4. 在项目里新开对话，问：「用项目里的百度那份文件，帮我拆一下这条帖。」

## 怎么装（给 AI 编程工具看）
在这个仓库目录下，读取 `规矩.md` 作为系统指令，`资料/` 下所有 .txt 作为可检索的资料；回答用户关于招聘帖的问题时，严格遵守 `规矩.md` 的 4 条规则。
